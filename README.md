# 自邮取

![logo](logo.jpg)

查快递、取快递用的 Android 应用。接了快递100 API，输入单号就能查。快递到了会推通知，取件码从短信里自动提取。

## 功能

**查快递**
- 输入单号查询，自动识别快递公司（支持 3050 家）
- 批量查询，一次查多个
- 未签收、已签收、全部三个列表
- 物品备注，方便区分包裹
- 删除的快递进回收站，能恢复

**取件码**
- 自动读取短信里的取件码，按驿站地址分组
- 标记已取后可隐藏
- 一键跳转淘宝/拼多多身份码
- 支持自定义解析规则，处理格式特殊的短信

**界面**
- Telegram 风格动画：页面转场、列表入场、按压反馈
- 浅色/深色模式，跟随系统或手动切换
- 自定义底部导航栏，切换 tab 有动画

**其他**
- 打开 app 自动刷新，签收弹通知
- 检测到新版本会提示更新
- 30 天自动清理旧记录

## 使用

1. 去 [快递100 API](https://api.kuaidi100.com) 注册，拿到 Key 和 Customer
2. 打开 app，"我的"页面填入 Key 和 Customer
3. "查快递"页面输入单号查询
4. 快递列表页下拉刷新

## 小米手机

小米手机需要额外开启"通知类短信"权限才能读取取件码短信：

系统设置 → 应用管理 → 自邮取 → 开启"通知类短信"

## 技术栈

| 用途 | 方案 |
|------|------|
| 框架 | Flutter 3.x |
| 状态管理 | Riverpod |
| 网络 | dio |
| 存储 | Hive + SharedPreferences |
| 通知 | flutter_local_notifications |
| 短信 | flutter_sms_inbox |
